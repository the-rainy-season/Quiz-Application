# Quiz Application (C++)

## 📌 Project Description
A console-based Quiz Application developed using C++ by applying Object-Oriented Programming (OOPS) concepts. The application asks multiple-choice questions, evaluates user answers, calculates scores, and displays correct answers after quiz completion.

---

## 🚀 Features
- Multiple-choice quiz system
- Score calculation
- Displays correct answers
- User-friendly console interface
- OOPS-based implementation

---

## 🛠 Technologies Used
- C++
- OOPS Concepts
- STL Vector

---

## 📚 Concepts Applied
- Classes & Objects
- Constructors
- Encapsulation
- Functions
- Vectors
- Traversal Logic

---

## ▶️ How to Run
1. Open the project in VS Code or any C++ compiler
2. Compile the program
3. Run the executable file
4. Answer quiz questions interactively
